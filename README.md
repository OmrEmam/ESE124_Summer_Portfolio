## Featured Projects

### 1. Magic Counter

Reads integers one at a time and stops as soon as the same value shows up twice in a row, keeping a running count of positives, negatives, and zeros as it goes.

- **Skills demonstrated:** loops, flag variables, input validation, avoiding uninitialized-comparison bugs
- **Source and details:** [`01-early-program/`](01-early-program/)

### 2. CSV Grade Book

Reads a CSV file of student grades and prints each student's average, validating every line with `sscanf()`'s return value so a malformed line gets caught and reported instead of silently producing a wrong average.

- **Skills demonstrated:** file I/O, `sscanf()` parsing, input validation, error handling
- **Source and details:** [`02-midcourse-program/`](02-midcourse-program/)

### 3. BroBank

A small in-memory banking engine that queues transactions, processes deposits/withdrawals/transfers in order, supports undoing the most recent transaction, and tracks account-to-account transfers as a graph so money-flow reachability can be checked with BFS and DFS.

- **Skills demonstrated:** abstract data types, queues, stacks, graph traversal (BFS/DFS), testing
- **Source and details:** [`03-brobank/`](03-brobank/)
